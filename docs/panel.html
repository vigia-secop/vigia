Qué no hace este panel

No emite alertas y no califica ningún contrato. Muestra la forma de una ventana de contratación y el alcance real de cada medición.

Las Reglas —oferente único, plazo exprés, posible fraccionamiento, concentración— vendrán después, y ninguna se enciende sin calibrar antes contra datos reales. Una alerta inventada le costaría a alguien su reputación, y es exactamente lo que este proyecto no se puede permitir.
